# Mi café de cafetera italiana sale amargo, ¿qué estoy haciendo mal?

Claude Code con búsqueda web · ejecución 1 · 2026-11-11

Si el café de tu cafetera italiana sale amargo, lo más habitual es una combinación de estos fallos: molienda demasiado fina (sobreextrae y amarga; la moka pide molienda media-fina, no de espresso), fuego demasiado alto, compactar el café en el filtro (no se debe prensar en la moka) y dejar la cafetera al fuego después de que termine de salir el café. Soluciones: usa una molienda algo más gruesa, baja el fuego, no presiones el café y retira la cafetera en cuanto empiece el burbujeo. Si compras café molido, elige uno indicado para cafetera italiana/moka.
